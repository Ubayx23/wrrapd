# wrrapd

Untangle your mind.

A free reflection platform for overthinkers. Short, deep lessons on how your thoughts, urges and fears work, each ending with a prompt to take to paper. No subscriptions, no AI, and your journal never lives here.

## Status
Landing page in progress.

## Stack
Next.js 15, TypeScript, Tailwind CSS, Framer Motion, Supabase (auth, coming soon), Vercel.

## Run locally
npm install
npm run dev

Landing references live in docs/design/landing/. References for the in-app design, which is not decided yet, live in docs/design/app-later/.
